# Assignment 6: PySpark Data Processing

This assignment introduces basic PySpark concepts using the Superstore dataset. It shows how to load data, clean it, apply transformations, and save the results in different formats.

## Project Objective
This assignment focuses on learning PySpark through a simple data processing workflow.
The main goal is to load the Superstore dataset, clean and transform the data, and prepare it for analysis.
It also demonstrates how to save processed output in CSV and Parquet formats.

## Main Tasks Covered
- Create a Spark session and load the dataset
- Clean invalid values and handle missing data
- Apply transformations such as filtering, renaming, and casting
- Perform basic grouping and aggregation
- Save the processed output in CSV and Parquet formats
