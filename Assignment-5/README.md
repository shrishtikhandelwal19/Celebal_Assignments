# Assignment 5: Spark Superstore Analysis

This assignment uses PySpark to process the Superstore dataset and build a simple data pipeline.

## Key Topics

- Spark Fundamentals
- Data Cleaning
- Filtering
- Aggregations
- GroupBy Operations
- Schema Modifications
- Data Processing Pipeline

## Files

- `data/sample-superstore.csv` - Superstore dataset
- `notebook/spark_basics.ipynb` - PySpark notebook for processing
- `output/results.csv` - Result dataset output

## Notes

Open the notebook to review the PySpark workflow. The notebook shows how to load the data, clean it, filter records, group values, apply aggregations, and save the results.
